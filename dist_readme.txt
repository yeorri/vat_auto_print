■ 부가세 신고자료 자동 출력 (VatAutoPrint)

업체 명부를 등록하면 홈택스 세무대리 메뉴의 부가세 신고자료를
업체별로 자동 조회·출력(인쇄 또는 PDF 저장)하는 프로그램입니다.

── 설치 ──
1. 압축을 원하는 폴더에 풉니다.
2. VatAutoPrint.exe 실행.
3. 첫 실행 시 브라우저 구성요소(약 150MB)를 자동 다운로드합니다.
   인터넷 연결이 필요하며 몇 분 걸릴 수 있습니다. (최초 1회만)

── 사용 ──
1. 업체 명부: 엑셀 가져오기(열 제목: 업체명 / 사업자등록번호 / 예정신고)
   또는 상단 입력줄로 직접 추가. 예정신고 열은 O·1(예정신고 함) / X·0(안 함).
2. 조회 조건: 과세기간(년/기)과 확정·예정 신고시즌 선택.
3. 작업 선택: 출력할 자료를 켜고 끕니다.
4. 서류 처리: 인쇄(기본 프린터) 또는 PDF 저장.
   저장 폴더에는 PDF(업체별 하위폴더)·판매대행 엑셀·결과 엑셀이 저장됩니다.
5. 시작 → 열리는 브라우저에서 홈택스에 세무대리인으로 로그인하면
   자동으로 진행됩니다. (로그인은 프로그램에 저장되어 다음부터 생략)

── 자료 목록 ──
· 부가가치세 신고자료 통합조회
· 부가세신고용 (세금)계산서 합계표 — 전자세금계산서·전자계산서 × 매출·매입
· 신용카드/판매(결제)대행 매출자료 (+판매대행 정리본 엑셀)
· 현금영수증 매출총액
· 수출실적명세서

── 납부서 출력 (상단에서 모드 전환) ──
화면 상단 [자료 출력|납부서 출력]을 '납부서 출력'으로 바꾸면, 명부의 업체별로
부가세 신고내역을 조회해 최신 1건의 납부서를 PDF로 저장합니다(업체별 하위폴더).
· 납부기한을 한 번 입력하면 파일명에 들어갑니다. 파일명 형식은 자유 설정:
  예) [납부서]부가가치세_{업체명}_{납부기한} + 날짜형식 YY.MM.DD
      → [납부서]부가가치세_홍길동상사_26.07.27.pdf
· 이 모드는 명부의 '예정신고' 열이 없어도 실행됩니다.
· 실행 중에는 다른 프로그램 사용을 잠시 멈춰주세요 — 저장 창이 뜨는 순간
  세무사랑 등이 화면을 잡고 있으면 '인쇄 실패'가 날 수 있습니다(자동 재시도 1회).

── 참고 ──
· 사업자등록번호가 틀린 업체는 남은 작업을 건너뛰고 결과 엑셀에 기록됩니다.
· 실행 로그 원본은 프로그램 데이터 폴더의 logs\ 에 저장됩니다.
